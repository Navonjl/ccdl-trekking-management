# Viva Evaluation Rubric

Source: provided by user (examiner-side evaluation form)

---

The questions the examiner fills in during the viva. "Is MCQ" = the examiner
answers on a fixed scale/choice rather than free text.

| # | Question | Is MCQ |
| --- | --- | --- |
| 1 | Was the learner able to explain the project organization? (where controllers are, where Vue components, where celery jobs are, etc.) | True |
| 2 | Was the learner able to explain how the celery and redis are set up? (where the instance is created, where the configurations are, etc.) | True |
| 3 | Was the learner able to explain the database design or schema and the idea behind choosing such design? | True |
| 4 | Was the learner able to explain the complete application flow, i.e., how the control shifts from one Vue component to another? | True |
| 5 | Was the learner able to explain the purpose of using an API, endpoints implemented, and authentication mechanism? | True |
| 6 | Was the learner able to answer the first question on the backend? | True |
| 7 | Was the learner able to answer the second question on the backend? | True |
| 8 | Was the learner able to answer the first question on the frontend?? | True |
| 9 | Was the learner able to answer the second question on the frontend? | True |
| 10 | Was the learner able to make change to the backend (celery jobs, API etc.) when suggested? | True |
| 11 | Was the learner able to make change to the frontend (Vue) when suggested? | True |
| 12 | General Viva : How well the first question was answered? | True |
| 13 | General Viva : How well the second question was answered? | True |
| 14 | General Viva : How well the third question was answered? | True |
| 15 | General Viva : How well the fourth question was answered? | True |
| 16 | Rate the student in terms of knowledge, confidence and presentation skills? | True |
| 17 | Do you feel the student has copied and not created the project by themselves? Should this be reviewed? | True |
| 18 | Your Feedback for student. | False |
